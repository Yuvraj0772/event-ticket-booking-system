
# Event Ticket Booking System

A full-stack event ticket booking platform built with React,
Node.js, Express, MongoDB and Redis.

## Planned Features

- User authentication
- Event browsing and show selection
- Interactive seat selection
- Redis-based temporary seat locking
- Booking and payment simulation
- Redis caching and rate limiting
- Booking history
- Redis Pub/Sub notifications

## Tech Stack

- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB
- In-memory store: Redis
- Version control: Git + GitHub
